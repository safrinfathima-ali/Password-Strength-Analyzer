# Password Strength Analyzer

## Project Description
Password Strength Analyzer is a Python-based cybersecurity tool that evaluates password strength based on length, complexity and common password patterns.

## Technologies Used
- Python 3
- Regular Expressions
- Secrets Module
- String Module

## Key Features
1. Password length checking.
2. Uppercase and lowercase validation.
3. Number and special character validation.
4. Common password detection.
5. Password improvement suggestions.
6. Secure random password generation.

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Execute `python password_checker.py`.

## Learning Outcomes
- Understanding password security.
- Learning password validation.
- Understanding regular expressions.
- Introduction to secure random password generation.

## Security Note
The application does not save or transmit entered passwords.
